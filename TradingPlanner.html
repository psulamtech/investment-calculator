⚠️ Golden Rules for Averaging
📉 Averaging Down Rules
  • → Only average down if the thesis is still valid
  • → Never average down just because it's cheaper
  • → Max 1–2 additional buys — don't keep adding
  • → New buy must still have 3:1 risk/reward
  • → If it hits your original stop loss — EXIT, don't average
📈 Averaging Up Rules
  • → Only add to a position that is already profitable
  • → Add on breakouts or pullbacks to support
  • → Keep additional buy smaller than original (pyramid up)
  • → Raise your stop loss on the full position after adding
  • → Don't chase — only add if momentum confirms
Why You Need an Exit Plan the core problem with single exits
❌ The Problem — All-or-Nothing Exit
  • → Hold too long → winner reverses into a loss
  • → Exit early → watch it run 20% more without you
  • → Either way you feel like you made the wrong call
  • → Emotional exits destroy discipline over time
✅ The Solution — 3-Tier Partial Exit
  • → Tier 1 locks real profit early — you never lose money
  • → Tier 2 hits your planned target — mission accomplished
  • → Tier 3 runner lets you participate if it keeps going
  • → Pre-planned rules remove emotion from every exit

Why Most Stops Get Hit the real problem
❌ Fixed % Stop
A 5% stop ignores chart structure. Volatile stocks move 5% in a single day — you get stopped by noise, not by being wrong.
❌ Round Number Stop
Stops at $50.00 or just below a MA are hunted by algorithms. Price dips to grab them, then reverses — you're out before the real move.
❌ Late Entry Stop
Chasing an extended move means your valid stop is far away. You either accept huge risk or place it too tight — and get shaken out.

Stop Placement Rules memorize these
✅ Good Stop Habits
  • → Place stop based on chart structure, not a fixed %
  • → Add a small buffer (0.5–1%) beyond the structural level
  • → Let stop distance determine position size
  • → Wider stop = fewer shares, not more risk
  • → Only enter if 3:1 R/R is still valid at that stop
❌ Stop Mistakes to Avoid
  • → Never place stop at a round number ($50, $100)
  • → Never place stop exactly at the MA — add buffer
  • → Never widen your stop after entry to avoid loss
  • → Never enter a trade if the stop makes R/R less than 3:1
  • → Never ignore ATR — if stop < 1× ATR, it will be hit by noise
